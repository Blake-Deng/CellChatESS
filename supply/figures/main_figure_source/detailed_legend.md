# Figure 1 legend

**Figure 1. Performance and numerical validation of CellChatESS.** The results use the pinned CellChat 2.2.0.9001 baseline, CellChatESS 0.2.2 and, where indicated, AutoZyme 0.3.1; controlled or instrumented derivatives are identified explicitly. All primary performance comparisons use one thread per method in separate R processes. (A) Inference-call runtimes for Original CellChat and ESS across 12 datasets, six target sizes and three runs (216 paired runs; 129 distinct prepared inputs). Points are actual measurements; circles and error bars show medians and interquartile ranges. Both external timers span the complete inference call, including internal conversion and initialization, and exclude process startup, package/input loading, output serialization and downstream analysis. The median paired Original/ESS ratio is 27.48× (95% dataset-cluster percentile bootstrap CI, 22.31–38.47×; 10,000 resamples). Repeated sizes/runs are not independent biological replicates. (B) Paired inference-call times for AutoZyme and ESS on 32 inputs from 12 datasets, with all six method orders (192 blocks). Symbols identify input strata; the dashed line is equality. The pooled paired AutoZyme/ESS ratio is 1.753×; ESS is faster in 191 blocks. (C) Six-stage controlled ablation, with three timing repeats per stage: A0, Original CellChat; A1, dense Rcpp with all signaling genes; A2, dense Rcpp with projected genes; A3, on-demand aggregation without caching or pruning; A4, cached ESS without pruning; A5, full ESS. Lines connect stage medians for three different datasets (10X 1k, EGAS00001004422 10k and PRJNA638151 50k), not a within-dataset cell-count scaling series. A3 is slower than the dense path; caching removes repeated aggregation, and pruning yields a further reduction. These results do not establish independent benefits for every ESS-specific optimization. (D,E) Aggregate communication networks from saved outputs of Original CellChat 2.2.0.9001 (D) and final CellChatESS 0.2.2 (E) for the oligodendroglioma example PRJNA289244 (1,000 cells, nine groups and 1,128 LR interactions). Node sizes reflect cell numbers; edge widths show the sum of communication probabilities over LR interactions with empirical p < 0.05. Edges are colored by the sender, and arrows indicate direction. Both panels use identical layouts and common node and edge scales. Cell-group display annotations are retained from the original illustration; the new output cluster identifiers and their display-name mapping are supplied. (F) Probability agreement for a newly run 10X 1k example (K = 12; maximum absolute difference 5.55e-17). Across all 216 new pairs, the maximum absolute probability difference is 1.11 × 10⁻¹⁶; empirical p-value tensors and default aggregate counts are elementwise identical. Probability tensors agree to floating-point precision and are not bitwise identical. (G) Full-process peak RSS for the three methods in 192 blocks, with actual measurements, medians and IQRs. (H) Peak process RSS saved by ESS, calculated as the AutoZyme peak RSS minus the ESS peak RSS within each paired block and expressed in MiB. The boxes span the interquartile range, the vertical lines mark the medians (labeled to the nearest MiB), and the whiskers extend from the minimum to the maximum. The 1k, 10k-or-full and 50k-or-full strata contain 72, 72 and 48 paired blocks, respectively. ESS used less peak memory in all 192 blocks. (I) Paired non-spatial Xenium stress test using one single-threaded run per method on the same input (1,156,091 cells, 2,357 groups, 627 ligand–receptor interactions and 100 bootstrap replicates). Coordinates were used only to assign cells to a 50 × 50 grid. Spatial inference and distance constraints were disabled. Inference time covers the inference function call, including matrix conversion and initialization (original CellChat, 17,186.512 s, and ESS, 1,282.588 s, a 13.40× speedup). Whole-process wall time includes startup, package and input loading, input checks, inference, default network aggregation (aggregateNet), saving results and exit (18,092.00 s and 2,251.84 s, respectively, an 8.03× speedup). GNU time recorded whole-process wall time and peak resident set size (RSS), which was 250.08 GiB for original CellChat and 198.62 GiB for ESS. The input matrix occupied 0.894 GiB as an R object. The dense probability and p-value tensors each required 25.95 GiB of data storage (51.90 GiB combined), excluding object overhead. Storage per tensor scales as O(n_LR K²). (J) Ligand-receptor bubble plots from the same saved outputs as D/E, retaining the original selection and ordering of 16 LR interactions, three sender groups and 24 communicating group pairs. Each method shows 73 positive-probability records with empirical p < 0.05. Bubble color and size increase with the shared visualization score -1/log(P), where P is the communication probability; colorbar ticks are labeled in probability units through the inverse transformation. Full cell-group names are displayed. The raw probability tensors differ by at most 5.55 × 10⁻¹⁷ for this example, while empirical p values and default aggregate counts are elementwise identical.
